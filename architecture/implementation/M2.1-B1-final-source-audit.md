## 3. Argument Validation Audit

### 3.1. Construction Paths and Visibility
1. **Public Path (`QemuProcessConfig::to_args`):**
   ```rust
   pub fn to_args(&self) -> Result<Vec<String>, QemuError> {
       self.validate()?;
       Ok(self.to_args_internal())
   }
   ```
   - **Validation Gate:** `self.validate()?` is executed synchronously on `&self` before any argument vector is allocated.
   - **Immutability & TOCTOU Immunity:** Because `&self` is borrowed immutably, Rust's borrow checker guarantees that no concurrent or aliased mutable access (`&mut self`) can mutate configuration fields between validation and argument generation.
   - **Return Tokenization:** Returns `Result<Vec<String>, QemuError>`. Every argument is returned as a discrete argument token. No concatenated command-line string is produced, eliminating shell-parsing and word-splitting vulnerabilities.
2. **Crate-Private Path (`QemuProcessConfig::to_args_internal`):**
   - Marked `pub(crate)` for future use by the process supervisor (`supervisor.rs` in B3/B4) once validated.
   - **Audit of All Call Sites:** The only call site across the entire workspace is `crates/terminest-core/src/backend/qemu/config.rs:255` inside `to_args()`, which immediately succeeds `self.validate()?`.
   - Zero unvalidated call sites exist in the repository.
3. **Exclusion of Arbitrary Arguments:**
   - No `extra_args`, raw string slices, or untyped flags exist in `QemuProcessConfig`. Every command argument is derived strictly from typed struct fields and enums.

## 4. CPU Validation & Injection Resistance Audit

### 4.1. Grammar Specification vs. Implementation
In `QemuCpuConfig::validate()`:
1. **CPU Model Grammar:**
   - Target Regex: `^[a-zA-Z0-9_.-]+$`
   - Implementation:
     ```rust
     if self.model.is_empty()
         || !self.model.chars().all(|c| c.is_ascii_alphanumeric() || c == '_' || c == '.' || c == '-')
     {
         return Err(QemuError::ConfigValidation(...));
     }
     ```
   - **Accepted Values:** `qemu64`, `Skylake-Client`, `host`, `EPYC-v4`, `core2duo`.
   - **Rejected Values:**
     - Comma `,` (QEMU sub-option delimiter): `Skylake,kernel-irqchip=off` rejected.
     - Equals `=` (QEMU property delimiter): `Skylake=on` rejected.
     - Semicolon `;` / Shell metacharacters (`&`, `|`, `$`, `` ` ``): `Skylake;reboot` rejected.
     - Whitespace: `Skylake cpu` rejected.
     - Null bytes: `Skylake\0evil` rejected.
     - Empty string `""`: rejected.
2. **CPU Feature Grammar:**
   - Target Regex: `^[+-][a-zA-Z0-9_.-]+$`
   - Implementation:
     ```rust
     for feat in &self.features {
         if feat.len() < 2
             || (!feat.starts_with('+') && !feat.starts_with('-'))
             || !feat[1..].chars().all(|c| c.is_ascii_alphanumeric() || c == '_' || c == '.' || c == '-')
         {
             return Err(QemuError::ConfigValidation(...));
         }
     }
     ```
   - **Accepted Values:** `+aes`, `-hle`, `+invtsc`, `-vmx`.
   - **Rejected Values:**
     - Missing prefix: `aes` rejected (`feat.len() < 2 || (!starts_with('+') && !starts_with('-'))`).
     - Empty name: `+` and `-` rejected (`feat.len() < 2`).
     - Property injection: `+aes=on` rejected (contains `=`).
     - Sub-option injection: `+aes,hack` rejected (contains `,`).
     - Shell injection: `+aes;drop` rejected (contains `;`).
     - Whitespace: `+aes foo` rejected.
3. **Compound Argument Emission:**
   - Emitted via `cpu.to_qemu_arg()`.
   - Produces discrete arguments `["-cpu", "<model>[,+feat1,-feat2]"]`.
   - `-cpu` is passed as an isolated argv token to the OS exec/spawn call, preventing shell interpolation.

## 5. Accelerator Policy Audit

### 5.1. Windows WHPX Enforcement (§8.1)
- **Public API Contract:**
  ```rust
  pub fn validate(&self) -> Result<(), QemuError> {
      self.validate_internal(false)
  }
  ```
- **Windows Implementation:**
  ```rust
  #[cfg(windows)]
  {
      if self.accelerator == QemuAccelerator::Tcg && !allow_tcg {
          return Err(QemuError::ConfigValidation(
              "TCG software emulation is prohibited on Windows production paths; WHPX is required".into(),
          ));
      }
      if self.accelerator == QemuAccelerator::Kvm {
          return Err(QemuError::ConfigValidation(
              "KVM acceleration is not available on Windows; WHPX is required".into(),
          ));
      }
  }
  ```
- **Zero Public Bypass:**
  - `validate_internal()` is strictly private (`fn`) to `config.rs`.
  - It is not `pub` and not `pub(crate)`.
  - `#[doc(hidden)]` is not used.
  - Rust compiler rules make it impossible for any external crate or external module to invoke `validate_internal(true)`.
  - On Windows, `QemuAccelerator::Whpx` is the only variant that can pass public validation.
  - Automatic fallback from WHPX to TCG does not exist.
- **Cross-Platform Safety:**
  - On non-Windows targets (`#[cfg(not(windows))]`), configuring `Whpx` returns `Err(QemuError::ConfigValidation("WHPX acceleration is only supported on Windows"))`.

/// Typed CPU configuration with model and optional feature flags.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct QemuCpuConfig {
    pub model: String,
    pub features: Vec<String>,
}

impl QemuCpuConfig {
    /// Creates a new CPU configuration with a base model and no features.
    pub fn new(model: impl Into<String>) -> Self {
        Self {
            model: model.into(),
            features: Vec::new(),
        }
    }

    /// Creates a CPU configuration with a base model and explicit feature flags.
    pub fn with_features(model: impl Into<String>, features: Vec<String>) -> Self {
        Self {
            model: model.into(),
            features,
        }
    }

    /// Validates the CPU model and feature strings against QEMU option grammar rules.
    pub fn validate(&self) -> Result<(), QemuError> {
        if self.model.is_empty()
            || !self
                .model
                .chars()
                .all(|c| c.is_ascii_alphanumeric() || c == '_' || c == '.' || c == '-')
        {
            return Err(QemuError::ConfigValidation(format!(
                "Invalid CPU model '{}': must match ^[a-zA-Z0-9_.-]+$",
                self.model
            )));
        }

        for feat in &self.features {
            if feat.len() < 2
                || (!feat.starts_with('+') && !feat.starts_with('-'))
                || !feat[1..]
                    .chars()
                    .all(|c| c.is_ascii_alphanumeric() || c == '_' || c == '.' || c == '-')
            {
                return Err(QemuError::ConfigValidation(format!(
                    "Invalid CPU feature '{}': must match ^[+-][a-zA-Z0-9_.-]+$",
                    feat
                )));
            }
        }

        Ok(())
    }

    /// Formats the CPU argument for QEMU: `<model>[,+feat1,-feat2,...]`.
    pub(crate) fn to_qemu_arg(&self) -> String {
        if self.features.is_empty() {
            self.model.clone()
        } else {
            format!("{},{}", self.model, self.features.join(","))
        }
    }
}

    ///
    /// On Windows (`cfg(windows)`), this unconditionally enforces that `accelerator`
    /// is `QemuAccelerator::Whpx`. Automatic fallback or configuration of TCG on
    /// Windows is strictly rejected.
    pub fn validate(&self) -> Result<(), QemuError> {
        self.validate_internal(false)

    /// Private internal validation engine.
    /// Visible strictly within `crate::backend::qemu::config`.
    fn validate_internal(&self, allow_tcg: bool) -> Result<(), QemuError> {
        if self.executable.as_os_str().is_empty() {
            return Err(QemuError::ConfigValidation(
                "Executable path cannot be empty".to_string(),
            ));
        }

        #[cfg(windows)]
        {
            if self.accelerator == QemuAccelerator::Tcg && !allow_tcg {
                return Err(QemuError::ConfigValidation(
                    "TCG software emulation is prohibited on Windows production paths; WHPX is required".into(),
                ));
            }
            if self.accelerator == QemuAccelerator::Kvm {
                return Err(QemuError::ConfigValidation(
                    "KVM acceleration is not available on Windows; WHPX is required".into(),
                ));
            }
        }

        #[cfg(not(windows))]
        {
            if self.accelerator == QemuAccelerator::Whpx {
                return Err(QemuError::ConfigValidation(
                    "WHPX acceleration is only supported on Windows".into(),
                ));
            }
        }

        if let Some(ref cpu) = self.cpu {
            cpu.validate()?;
        }

        if let Some(smp) = self.smp_vcpus {
            if smp == 0 || smp > 256 {
                return Err(QemuError::ConfigValidation(format!(
                    "Invalid SMP vCPU count {}: must be between 1 and 256",
                    smp
                )));
            }
        }

        if let Some(mem) = self.memory_mb {
            if !(128..=1_048_576).contains(&mem) {
                return Err(QemuError::ConfigValidation(format!(
                    "Invalid memory size {} MB: must be between 128 MB and 1048576 MB",
                    mem
                )));
            }
        }

        Ok(())
    }

    /// Constructs the discrete argument list for QEMU process invocation.
    ///
    /// This method unconditionally validates the configuration before constructing
    /// arguments. If validation fails (e.g. invalid CPU model, unauthorized TCG on Windows,
    /// or out-of-range memory/SMP), returns `Err(QemuError::ConfigValidation)`.
    pub fn to_args(&self) -> Result<Vec<String>, QemuError> {
        self.validate()?;
        Ok(self.to_args_internal())
    }

    /// Internal argument construction without public validation.
    pub(crate) fn to_args_internal(&self) -> Vec<String> {
        let mut args = vec![
            "-machine".to_string(),

        if let Some(smp) = self.smp_vcpus {

            args.push(smp.to_string());

            args.push("-m".to_string());
            args.push(format!("{}M", mem));

        args.push("-display".to_string());
        args.push(self.display.as_str().to_string());

        args

use std::path::PathBuf;
use thiserror::Error;

/// Domain errors produced by the QEMU process management subsystem.
#[derive(Debug, Error, Clone, PartialEq, Eq)]
pub enum QemuError {
    #[error("QEMU binary not found: {0}")]
    BinaryNotFound(PathBuf),

    #[error("Failed to parse QEMU version output: {0}")]
    VersionParseError(String),

    #[error("Required QEMU accelerator unavailable: {0}")]
    AcceleratorUnavailable(String),

    #[error("QEMU version policy violation: {0}")]
    VersionPolicyViolation(String),

    #[error("Invalid QEMU process configuration: {0}")]
    ConfigValidation(String),

    #[error("Failed to assign QEMU process to Windows Job Object")]
    JobObjectAssignmentFailed,

    #[error(
        "QEMU process unexpectedly exited ({status}): {stderr_tail}",
        status = match exit_status {
            Some(code) => format!("code {code}"),
            None => "signal".to_string(),
        }
    )]
    ProcessUnexpectedExit {
        exit_status: Option<i32>,
        stderr_tail: String,
    },

    #[error("QEMU process management system error: {0}")]
    System(String),

    #[error("Operation timed out after {0:?}")]
    Timeout(std::time::Duration),
}

impl From<std::io::Error> for QemuError {
    fn from(err: std::io::Error) -> Self {
        Self::System(err.to_string())
    }
}

## 13. Stage B1 Final Policy Correction, Regression Testing, and Acceptance Synchronization

### 13.1. Policy Inconsistency Finding

- **Finding ID:** `FINDING-B1-04`
- **Severity:** Medium
- **Location:** `crates/terminest-core/src/backend/qemu/config.rs:200-221`
- **Description:** The `QemuAccelerator::Tcg` documentation states that TCG is restricted to test harnesses. However, `validate_internal()` previously checked TCG only within `#[cfg(windows)]`. On non-Windows platforms, public `validate()` permitted TCG instead of enforcing KVM as the required production accelerator. Additionally, the test fixture `valid_minimal_config()` configured TCG on non-Windows.
- **Impact:** An application invoking `config.validate()` on non-Windows could configure and launch an unaccelerated TCG virtual machine in production without activating an explicit test seam.

---

### 13.2. Policy Correction

1. **Platform-Independent TCG Prohibition:**
   The check `if self.accelerator == QemuAccelerator::Tcg && !allow_tcg` was moved outside all `#[cfg(...)]` blocks, guaranteeing that TCG software emulation is unconditionally rejected on all production validation paths across all operating systems.
2. **Platform-Specific Accelerator Rules:**
   - On Windows: WHPX is required. KVM is rejected (`KVM acceleration is not available on Windows; WHPX is required`). TCG is rejected on production paths (`TCG software emulation is prohibited on Windows production paths; WHPX is required`).
   - On non-Windows (Linux): KVM is required. WHPX is rejected (`WHPX acceleration is only supported on Windows`). TCG is rejected on production paths (`TCG software emulation is prohibited on non-Windows production paths; KVM is required`).
   - Test Seam: `validate_internal(allow_tcg = true)` permits TCG on all platforms within internal unit tests.
3. **Test Fixture Alignment:**
   Updated `valid_minimal_config()` so that `#[cfg(not(windows))]` configures `QemuAccelerator::Kvm` as the production accelerator.
