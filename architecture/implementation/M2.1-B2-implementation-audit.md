## 3. Executable Discovery Engine Analysis

The executable discovery engine is implemented in `crates/terminest-core/src/backend/qemu/discovery.rs` as `QemuDiscovery`.

### 3.1. Prioritized Resolution Algorithm
The resolution algorithm strictly evaluates sources in sequence without premature short-circuiting:
1. **Explicit Parameter (`Option<&Path>`):**
   If passed by the caller, it is directly validated via `is_executable(path)`. If valid, it is returned. If missing or not an executable file, resolution immediately aborts with `Err(QemuError::BinaryNotFound(path.to_path_buf()))`. It does **not** fall back to system heuristics, preserving caller intent.
2. **Environment Variable (`TERMINEST_QEMU_PATH`):**
   If set and non-empty, the path is validated via `is_executable(&path)`. If valid, it is returned. If invalid, resolution aborts with `Err(QemuError::BinaryNotFound(path))`.
3. **Platform System Paths (`platform_system_paths()`):**
   - Windows:
     - `%ProgramFiles%\qemu\qemu-system-x86_64.exe`
     - `%ProgramFiles(x86)%\qemu\qemu-system-x86_64.exe`
     - `%LOCALAPPDATA%\Programs\qemu\qemu-system-x86_64.exe`
     - `%ProgramData%\chocolatey\bin\qemu-system-x86_64.exe`
     - Hardcoded standard fallback paths `C:\Program Files\qemu\qemu-system-x86_64.exe` and `C:\Program Files (x86)\qemu\qemu-system-x86_64.exe` in case environment variables are undefined.
   - Linux:
     - `/usr/bin/qemu-system-x86_64`
     - `/usr/local/bin/qemu-system-x86_64`
4. **System `PATH` Lookup (`system_path_dirs()`):**
   Iterates through directories in `std::env::var_os("PATH")` using `std::env::split_paths`, looking for `qemu-system-x86_64.exe` on Windows or `qemu-system-x86_64` on Unix.
5. **Terminal Failure:**
   If no candidate is found, returns `Err(QemuError::BinaryNotFound(PathBuf::from(default_binary_name())))`.

### 3.2. Native Executable Validation (`is_executable`)
File validation avoids heuristic guesses:
- Checks `path.is_file()` to reject directories, sockets, symlink loops, or missing files.
- On Windows: verifies file extension matches `exe`, `cmd`, or `bat` case-insensitively (`ext.eq_ignore_ascii_case("exe")`).
- On Unix: checks file permissions mode bits for user, group, or other execute permission (`permissions().mode() & 0o111 != 0`).

## 4. QEMU Version Parser & Policy Analysis

Implemented in `crates/terminest-core/src/backend/qemu/capabilities.rs`.

### 4.1. Version Format Robustness
QEMU version strings vary across upstream releases, Linux distributions, and custom builds. The parser `parse_version` handles all formats:
- **Standard release:** `QEMU emulator version 9.2.0` -> `major=9, minor=2, patch=0, suffix=None`.
- **Development snapshot with parenthesized Git describe:** `QEMU emulator version 11.1.0 (v11.1.0-12130-ge470268ff4)` -> `major=11, minor=1, patch=0, suffix=Some("v11.1.0-12130-ge470268ff4")`.
- **Direct hyphenated snapshot token:** `11.1.0-12130-ge470268ff4` -> `major=11, minor=1, patch=0, suffix=Some("12130-ge470268ff4")`.
- **Distribution package:** `QEMU emulator version 8.2.2 (Debian 1:8.2.2+ds-0ubuntu1)` -> `major=8, minor=2, patch=2, suffix=Some("Debian 1:8.2.2+ds-0ubuntu1")`.
- **Release candidates:** `QEMU emulator version 9.0.0-rc1` -> `major=9, minor=0, patch=0, suffix=Some("rc1")`.

### 4.2. Commit Hash Extraction
The `commit_hash(&self) -> Option<&str>` method locates the `-g` Git commit prefix in the suffix and extracts 7 to 40 hexadecimal characters. For `11.1.0-12130-ge470268ff4`, it extracts `e470268ff4`.

### 4.3. SemVer Precedence & Comparison
Implements `Ord` and `PartialOrd` according to SemVer 2.0 specifications:
- Primary comparison: `(major, minor, patch)`.
- Prerelease rule: a release with a suffix has lower precedence than a final release with the same core version (e.g. `9.0.0-rc1` < `9.0.0`).
- Equal core versions without suffixes are equal (`(8, 0, 0) == (8, 0, 0)`).
- Snapshot comparison: `11.1.0-snapshot` > `8.0.0` because `(11, 1, 0) > (8, 0, 0)`.

### 4.4. Version Policy Enforcement
`QemuVersionPolicy` specifies:
- `min_version: (8, 0, 0)` provisional default.
- `allow_snapshots: true` (emits structured diagnostic warning via `tracing::warn!`).
- `enforce_version: bool` (can be toggled for test harnesses or explicit user overrides).

## 5. Accelerator Capability Probing & Safety Analysis

### 5.1. Accelerator Parsing (`parse_accelerators`)
Parses `qemu-system-x86_64 -accel help` output:
- Skips header banners (e.g. `Accelerators supported in QEMU binary:`).
- Parses recognized tokens: `whpx`, `kvm`, `tcg` (case-insensitive, whitespace-trimmed).
- Safely ignores third-party or platform-unrelated accelerators (`hax`, `hvf`, `xen`, `nvmm`).
- Deduplicates accelerators while preserving detection order.
- Returns `Err(QemuError::AcceleratorUnavailable)` if output is empty or contains zero recognized accelerators.

### 5.2. Platform Enforcement
- **Windows:** Production paths unconditionally require `QemuAccelerator::Whpx`. If the binary only supports `tcg`, validation fails immediately with `QemuError::AcceleratorUnavailable`.
- **Linux:** Requires `QemuAccelerator::Kvm` AND verifies `/dev/kvm` exists with read/write access.

## 6. Bounded Subprocess Execution Architecture

The bounded execution engine `run_process_bounded` guarantees safety against hostile or runaway processes:

1. **Zero Shell Wrapper:** Direct execution via `std::process::Command::new(program).args(args)`. No `cmd.exe /c` or `/bin/sh -c` is invoked.
2. **Headless Execution:** On Windows, configures `CREATE_NO_WINDOW (0x0800_0000)` to prevent UI window flickering during background probing.
3. **Hard Timeout Enforcement:** The main thread spawns an I/O worker thread and waits on `std::sync::mpsc::Receiver::recv_timeout(5s)`. If the probe hangs:
   - Calls `child.kill()` (`TerminateProcess` / `SIGKILL`).
   - Calls `child.wait()` to reap the process and eliminate zombie table entries.
   - Joins the reader thread cleanly (EOF is triggered when pipe write handles close).
   - Returns `Err(QemuError::Timeout(Duration::from_secs(5)))`.
4. **Bounded Memory Ceiling:** Pipes are read using `(&mut stdout).take(65_536).read_to_end(&mut out_buf)`. Memory is hard-capped at 64 KiB, preventing buffer bloat or memory exhaustion.
5. **Unexpected Exit Diagnostics:** If exit status is non-zero, captures stderr tail up to 64 KiB and returns `QemuError::ProcessUnexpectedExit { exit_status, stderr_tail }`.

//! QEMU capability probing, version parsing, and version policy enforcement.

use std::fmt;
use std::str::FromStr;

use super::config::QemuAccelerator;
use super::error::QemuError;

/// Parsed semantic version representation of a QEMU binary.
#[derive(Debug, Clone, PartialEq, Eq, Hash)]
pub struct QemuVersion {
    pub major: u32,
    pub minor: u32,
    pub patch: u32,
    pub suffix: Option<String>,
}

impl QemuVersion {
    /// Creates a new `QemuVersion` without a suffix.
    pub const fn new(major: u32, minor: u32, patch: u32) -> Self {
        Self {
            major,
            minor,
            patch,
            suffix: None,
        }
    }

    /// Creates a new `QemuVersion` with an explicit suffix (e.g. snapshot, prerelease, or build tag).
    pub fn with_suffix(major: u32, minor: u32, patch: u32, suffix: impl Into<String>) -> Self {
        Self {
            major,
            minor,
            patch,
            suffix: Some(suffix.into()),
        }
    }

    /// Parses QEMU version output (such as `qemu-system-x86_64 --version`).
    ///
    /// Accepts standard release strings (e.g. `QEMU emulator version 9.2.0`),
    /// snapshot strings (e.g. `QEMU emulator version 11.1.0 (v11.1.0-12130-ge470268ff4)`
    /// or `11.1.0-12130-ge470268ff4`), distro-modified versions
    /// (e.g. `QEMU emulator version 8.2.2 (Debian 1:8.2.2+ds-0ubuntu1)`),
    /// or bare semver triplets (`8.0.0`).
    pub fn parse(output: &str) -> Result<Self, QemuError> {
        parse_version(output)
    }

    /// Returns `true` if this version represents a development snapshot or prerelease.
    pub fn is_snapshot(&self) -> bool {
        self.suffix.is_some()
    }

    /// Extracts the Git commit hash from the suffix if present (e.g. from `-g<hash>` or `(v...-g<hash>)`).
    pub fn commit_hash(&self) -> Option<&str> {
        let suffix = self.suffix.as_deref()?;
        if let Some(pos) = suffix.find("-g") {
            let after_g = &suffix[pos + 2..];
            let hash_len = after_g
                .chars()
                .take_while(|c| c.is_ascii_hexdigit())
                .count();
            if hash_len >= 7 {
                return Some(&after_g[..hash_len]);
            }
        }
        None
    }
}

impl Ord for QemuVersion {
    fn cmp(&self, other: &Self) -> std::cmp::Ordering {
        match (self.major, self.minor, self.patch).cmp(&(other.major, other.minor, other.patch)) {
            std::cmp::Ordering::Equal => match (&self.suffix, &other.suffix) {
                (None, None) => std::cmp::Ordering::Equal,
                (Some(_), None) => std::cmp::Ordering::Less,
                (None, Some(_)) => std::cmp::Ordering::Greater,
                (Some(a), Some(b)) => a.cmp(b),
            },
            ord => ord,
        }
    }
}

impl PartialOrd for QemuVersion {
    fn partial_cmp(&self, other: &Self) -> Option<std::cmp::Ordering> {
        Some(self.cmp(other))
    }
}

impl fmt::Display for QemuVersion {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "{}.{}.{}", self.major, self.minor, self.patch)?;
        if let Some(ref suffix) = self.suffix {
            write!(f, "-{suffix}")?;
        }
        Ok(())
    }
}

impl FromStr for QemuVersion {
    type Err = QemuError;

    fn from_str(s: &str) -> Result<Self, Self::Err> {
        Self::parse(s)
    }
}

/// Parses a QEMU version string into a structured [`QemuVersion`].
pub fn parse_version(output: &str) -> Result<QemuVersion, QemuError> {
    if output.trim().is_empty() {
        return Err(QemuError::VersionParseError(
            "Version output is empty".to_string(),
        ));
    }

    // Cap scanning to 64 KiB to prevent DoS from runaway output
    let truncated = if output.len() > 65_536 {
        &output[..65_536]
    } else {
        output
    };

    let version_line = truncated
        .lines()
        .map(str::trim)
        .find(|line| !line.is_empty())
        .ok_or_else(|| {
            QemuError::VersionParseError("No non-empty line in version output".to_string())
        })?;

    const PREFIX: &str = "QEMU emulator version ";
    let target = if let Some(idx) = version_line.find(PREFIX) {
        &version_line[idx + PREFIX.len()..]
    } else if let Some(idx) = version_line.to_ascii_lowercase().find("version ") {
        &version_line[idx + "version ".len()..]
    } else {
        version_line
    };

    let target = target.trim();
    if target.is_empty() {
        return Err(QemuError::VersionParseError(
            "Version token is missing after prefix".to_string(),
        ));
    }

    let (first_token, rest_str) = match target.split_once(char::is_whitespace) {
        Some((first, rest)) => (first, Some(rest.trim())),
        None => (target, None),
    };

    let (version_core, inline_suffix) = if let Some(hyphen_idx) = first_token.find('-') {
        (
            &first_token[..hyphen_idx],
            Some(&first_token[hyphen_idx + 1..]),
        )
    } else {
        (first_token, None)
    };

    let semver_parts: Vec<&str> = version_core.split('.').collect();
    if semver_parts.len() != 3 {
        return Err(QemuError::VersionParseError(format!(
            "Expected 3 version components (major.minor.patch), found {}: {:?}",
            semver_parts.len(),
            version_core
        )));
    }

    let major = semver_parts[0]
        .parse::<u32>()
        .map_err(|e| QemuError::VersionParseError(format!("Invalid major version: {e}")))?;
    let minor = semver_parts[1]
        .parse::<u32>()
        .map_err(|e| QemuError::VersionParseError(format!("Invalid minor version: {e}")))?;
    let patch = semver_parts[2]
        .parse::<u32>()
        .map_err(|e| QemuError::VersionParseError(format!("Invalid patch version: {e}")))?;

    let suffix = if let Some(s) = inline_suffix {
        Some(s.to_string())
    } else if let Some(rest) = rest_str {
        let cleaned = rest.trim_start_matches('(').trim_end_matches(')');
        if cleaned.is_empty() {
            None
        } else {
            Some(cleaned.to_string())
        }
    } else {
        None
    };

    Ok(QemuVersion {
        major,
        minor,
        patch,
        suffix,
    })
}

/// Parses the output of `qemu-system-x86_64 -accel help` to extract supported accelerators.
pub fn parse_accelerators(output: &str) -> Result<Vec<QemuAccelerator>, QemuError> {
    if output.trim().is_empty() {
        return Err(QemuError::AcceleratorUnavailable(
            "Accelerator output is empty".to_string(),
        ));
    }

    let mut accelerators = Vec::new();

    for line in output.lines() {
        let trimmed = line.trim();
        if trimmed.is_empty() {
            continue;
        }
        if trimmed.to_ascii_lowercase().starts_with("accelerator") {
            continue;
        }

        for token in trimmed.split_whitespace() {
            let lower = token.to_ascii_lowercase();
            let parsed = match lower.as_str() {
                "whpx" => Some(QemuAccelerator::Whpx),
                "kvm" => Some(QemuAccelerator::Kvm),
                "tcg" => Some(QemuAccelerator::Tcg),
                _ => None,
            };

            if let Some(accel) = parsed {
                if !accelerators.contains(&accel) {
                    accelerators.push(accel);
                }
            }
        }
    }

    if accelerators.is_empty() {
        return Err(QemuError::AcceleratorUnavailable(
            "No known accelerators found in QEMU -accel help output".to_string(),
        ));
    }

    Ok(accelerators)
}

/// Configurable policy for QEMU version and release provenance validation.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct QemuVersionPolicy {
    /// Minimum required (major, minor, patch) version. Provisional baseline: `(8, 0, 0)`.
    pub min_version: (u32, u32, u32),
    /// Whether development snapshots and pre-releases are permitted.
    pub allow_snapshots: bool,
    /// Whether version enforcement is active (can be disabled for explicit overrides/testing).
    pub enforce_version: bool,
}

impl Default for QemuVersionPolicy {
    fn default() -> Self {
        Self {
            min_version: (8, 0, 0),
            allow_snapshots: true,
            enforce_version: true,
        }
    }
}

impl QemuVersionPolicy {
    /// Creates a new custom version policy.
    pub const fn new(
        min_version: (u32, u32, u32),
        allow_snapshots: bool,
        enforce_version: bool,
    ) -> Self {
        Self {
            min_version,
            allow_snapshots,
            enforce_version,
        }
    }

    /// Validates a parsed [`QemuVersion`] against this policy.
    pub fn validate(&self, version: &QemuVersion) -> Result<(), QemuError> {
        if !self.enforce_version {
            return Ok(());
        }

        let min = QemuVersion::new(self.min_version.0, self.min_version.1, self.min_version.2);

        if version < &min {
            return Err(QemuError::VersionPolicyViolation(format!(
                "QEMU version {version} is below minimum required version {}.{}.{}",
                self.min_version.0, self.min_version.1, self.min_version.2
            )));
        }

        if version.is_snapshot() {
            if !self.allow_snapshots {
                return Err(QemuError::VersionPolicyViolation(format!(
                    "QEMU snapshot release {version} is disallowed by version policy"
                )));
            }
            tracing::warn!(
                version = %version,
                "Using provisional QEMU snapshot release; full multi-version qualification is pending"
            );
        }

        Ok(())
    }
}

/// Probed capabilities and metadata of a QEMU binary.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct QemuCapabilities {
    /// Parsed version of the QEMU binary.
    pub version: QemuVersion,
    /// List of accelerators compiled into the QEMU binary.
    pub accelerators: Vec<QemuAccelerator>,
}

impl QemuCapabilities {
    /// Creates a new `QemuCapabilities` instance.
    pub const fn new(version: QemuVersion, accelerators: Vec<QemuAccelerator>) -> Self {
        Self {
            version,
            accelerators,
        }
    }

    /// Checks if a specific accelerator is supported by the QEMU binary.
    pub fn supports_accelerator(&self, accel: QemuAccelerator) -> bool {
        self.accelerators.contains(&accel)
    }

    /// Verifies that a specific accelerator is supported, returning [`QemuError::AcceleratorUnavailable`] if not.
    pub fn validate_accelerator_support(&self, accel: QemuAccelerator) -> Result<(), QemuError> {
        if !self.supports_accelerator(accel) {
            return Err(QemuError::AcceleratorUnavailable(format!(
                "Required accelerator '{}' is not supported by QEMU binary",
                accel.as_str()
            )));
        }
        Ok(())
    }

    /// Validates that the host platform's required hardware accelerator is supported.
    ///
    /// - On Windows: requires `QemuAccelerator::Whpx`.
    /// - On Linux: requires `QemuAccelerator::Kvm` and accessible `/dev/kvm`.
    pub fn validate_platform_support(&self) -> Result<(), QemuError> {
        #[cfg(windows)]
        {
            if !self.supports_accelerator(QemuAccelerator::Whpx) {
                return Err(QemuError::AcceleratorUnavailable(
                    "WHPX acceleration is required on Windows, but QEMU binary does not support it"
                        .to_string(),
                ));
            }
        }
        #[cfg(target_os = "linux")]
        {
            if !self.supports_accelerator(QemuAccelerator::Kvm) {
                return Err(QemuError::AcceleratorUnavailable(
                    "KVM acceleration is required on Linux, but QEMU binary does not support it"
                        .to_string(),
                ));
            }
            let kvm_path = std::path::Path::new("/dev/kvm");
            if !kvm_path.exists() {
                return Err(QemuError::AcceleratorUnavailable(
                    "KVM device /dev/kvm does not exist on host".to_string(),
                ));
            }
            match std::fs::OpenOptions::new()
                .read(true)
                .write(true)
                .open(kvm_path)
            {
                Ok(_) => {}
                Err(e) => {
                    return Err(QemuError::AcceleratorUnavailable(format!(
                        "/dev/kvm is not accessible (read/write): {e}"
                    )));
                }
            }
        }
        Ok(())
    }
}

//! QEMU executable discovery, system resolution, and bounded capability probing.

use std::path::{Path, PathBuf};
use std::time::Duration;

use super::capabilities::{parse_accelerators, parse_version, QemuCapabilities, QemuVersionPolicy};
use super::error::QemuError;

/// Default timeout for probing QEMU commands (`--version` and `-accel help`).
pub const DEFAULT_PROBE_TIMEOUT: Duration = Duration::from_secs(5);

/// Maximum output buffer capture size for probing commands (64 KiB).
pub const MAX_PROBE_OUTPUT_BYTES: usize = 65_536;

/// Primary facade for QEMU executable discovery and environment capability validation.
pub struct QemuDiscovery;

impl QemuDiscovery {
    /// Resolves the QEMU binary path following strict search precedence:
    ///
    /// 1. Explicit path parameter (if provided).
    /// 2. `TERMINEST_QEMU_PATH` environment variable.
    /// 3. Platform well-known installation paths.
    /// 4. System `PATH` directories.
    ///
    /// Returns [`QemuError::BinaryNotFound`] if no valid executable can be located.
    pub fn find_executable(explicit_path: Option<&Path>) -> Result<PathBuf, QemuError> {
        find_executable_in(
            explicit_path,
            |var| std::env::var(var).ok(),
            &platform_system_paths(),
            &system_path_dirs(),
        )
    }

    /// Probes the capabilities of the QEMU binary at `path` by executing
    /// `--version` and `-accel help` with bounded timeouts and memory caps.
    pub fn probe_executable(path: &Path) -> Result<QemuCapabilities, QemuError> {
        probe_executable_with_runner(
            path,
            &ProcessCommandRunner,
            DEFAULT_PROBE_TIMEOUT,
            MAX_PROBE_OUTPUT_BYTES,
        )
    }

    /// Discovers the QEMU executable, probes its capabilities, enforces the
    /// version policy, and validates platform hardware acceleration support.
    pub fn discover(
        explicit_path: Option<&Path>,
        policy: Option<&QemuVersionPolicy>,
    ) -> Result<(PathBuf, QemuCapabilities), QemuError> {
        discover_with_runner(
            explicit_path,
            policy,
            &ProcessCommandRunner,
            DEFAULT_PROBE_TIMEOUT,
            MAX_PROBE_OUTPUT_BYTES,
        )
    }
}

/// Abstract runner for executing probing commands with timeout and output bounds.
pub(crate) trait CommandRunner: Send + Sync {
    fn run_bounded(
        &self,
        program: &Path,
        args: &[&str],
        timeout: Duration,
        max_bytes: usize,
    ) -> Result<String, QemuError>;
}

/// Production command runner executing real host subprocesses.
pub(crate) struct ProcessCommandRunner;

impl CommandRunner for ProcessCommandRunner {
    fn run_bounded(
        &self,
        program: &Path,
        args: &[&str],
        timeout: Duration,
        max_bytes: usize,
    ) -> Result<String, QemuError> {
        run_process_bounded(program, args, timeout, max_bytes)
    }
}

/// Executes a child process directly (without a shell) with bounded execution time and memory.
fn run_process_bounded(
    program: &Path,
    args: &[&str],
    timeout: Duration,
    max_bytes: usize,
) -> Result<String, QemuError> {
    use std::io::Read;
    use std::process::{Command, Stdio};

    let mut cmd = Command::new(program);
    cmd.args(args);
    cmd.stdin(Stdio::null());
    cmd.stdout(Stdio::piped());
    cmd.stderr(Stdio::piped());

    #[cfg(windows)]
    {
        use std::os::windows::process::CommandExt;
        const CREATE_NO_WINDOW: u32 = 0x0800_0000;
        cmd.creation_flags(CREATE_NO_WINDOW);
    }

    let mut child = cmd.spawn().map_err(|e| {
        if e.kind() == std::io::ErrorKind::NotFound {
            QemuError::BinaryNotFound(program.to_path_buf())
        } else {
            QemuError::System(format!("Failed to spawn {}: {e}", program.display()))
        }
    })?;

    let mut stdout = child.stdout.take().ok_or_else(|| {
        QemuError::System("Failed to capture stdout pipe from child process".into())
    })?;
    let mut stderr = child.stderr.take().ok_or_else(|| {
        QemuError::System("Failed to capture stderr pipe from child process".into())
    })?;

    let (tx, rx) = std::sync::mpsc::channel();
    let reader_handle = std::thread::spawn(move || {
        let mut out_buf = Vec::new();
        let mut err_buf = Vec::new();
        let out_res = (&mut stdout)
            .take(max_bytes as u64)
            .read_to_end(&mut out_buf);
        let err_res = (&mut stderr)
            .take(max_bytes as u64)
            .read_to_end(&mut err_buf);
        let _ = tx.send((out_res, out_buf, err_res, err_buf));
    });

    match rx.recv_timeout(timeout) {
        Ok((out_res, out_buf, _err_res, err_buf)) => {
            let _ = reader_handle.join();

            let status = child
                .wait()
                .map_err(|e| QemuError::System(format!("Failed to wait for process exit: {e}")))?;

            if !status.success() {
                let stderr_tail = String::from_utf8_lossy(&err_buf).trim().to_string();
                return Err(QemuError::ProcessUnexpectedExit {
                    exit_status: status.code(),
                    stderr_tail,
                });
            }

            out_res.map_err(|e| QemuError::System(format!("Failed reading stdout: {e}")))?;
            let stdout_str = String::from_utf8(out_buf).map_err(|e| {
                QemuError::VersionParseError(format!("Output contains invalid UTF-8: {e}"))
            })?;

            Ok(stdout_str)
        }
        Err(std::sync::mpsc::RecvTimeoutError::Timeout) => {
            let _ = child.kill();
            let _ = child.wait();
            let _ = reader_handle.join();
            Err(QemuError::Timeout(timeout))
        }
        Err(std::sync::mpsc::RecvTimeoutError::Disconnected) => {
            let _ = child.kill();
            let _ = child.wait();
            let _ = reader_handle.join();
            Err(QemuError::System(
                "Output reader thread disconnected prematurely".into(),
            ))
        }
    }
}

/// Validates whether a path points to an existing executable file.
pub fn is_executable(path: &Path) -> bool {
    if !path.is_file() {
        return false;
    }

    #[cfg(windows)]
    {
        if let Some(ext) = path.extension().and_then(|s| s.to_str()) {
            ext.eq_ignore_ascii_case("exe")
                || ext.eq_ignore_ascii_case("cmd")
                || ext.eq_ignore_ascii_case("bat")
        } else {
            false
        }
    }

    #[cfg(unix)]
    {
        use std::os::unix::fs::PermissionsExt;
        if let Ok(metadata) = path.metadata() {
            metadata.permissions().mode() & 0o111 != 0
        } else {
            false
        }
    }
}

/// Returns the standard QEMU executable file name for the current platform.
pub const fn default_binary_name() -> &'static str {
    if cfg!(windows) {
        "qemu-system-x86_64.exe"
    } else {
        "qemu-system-x86_64"
    }
}

/// Collects well-known platform system installation paths.
pub fn platform_system_paths() -> Vec<PathBuf> {
    let mut paths = Vec::new();

    #[cfg(windows)]
    {
        if let Ok(prog_files) = std::env::var("ProgramFiles") {
            paths.push(
                PathBuf::from(prog_files)
                    .join("qemu")
                    .join("qemu-system-x86_64.exe"),
            );
        }
        if let Ok(prog_files_x86) = std::env::var("ProgramFiles(x86)") {
            paths.push(
                PathBuf::from(prog_files_x86)
                    .join("qemu")
                    .join("qemu-system-x86_64.exe"),
            );
        }
        if let Ok(local_appdata) = std::env::var("LOCALAPPDATA") {
            paths.push(
                PathBuf::from(local_appdata)
                    .join("Programs")
                    .join("qemu")
                    .join("qemu-system-x86_64.exe"),
            );
        }
        if let Ok(prog_data) = std::env::var("ProgramData") {
            paths.push(
                PathBuf::from(prog_data)
                    .join("chocolatey")
                    .join("bin")
                    .join("qemu-system-x86_64.exe"),
            );
        }

        // Hardcoded standard Windows fallbacks in case environment variables are missing
        let std_c_prog = PathBuf::from("C:\\Program Files\\qemu\\qemu-system-x86_64.exe");
        if !paths.contains(&std_c_prog) {
            paths.push(std_c_prog);
        }
        let std_c_prog_x86 = PathBuf::from("C:\\Program Files (x86)\\qemu\\qemu-system-x86_64.exe");
        if !paths.contains(&std_c_prog_x86) {
            paths.push(std_c_prog_x86);
        }
    }

    #[cfg(not(windows))]
    {
        paths.push(PathBuf::from("/usr/bin/qemu-system-x86_64"));
        paths.push(PathBuf::from("/usr/local/bin/qemu-system-x86_64"));
    }

    paths
}

/// Returns directories parsed from the host `PATH` environment variable.
pub fn system_path_dirs() -> Vec<PathBuf> {
    match std::env::var_os("PATH") {
        Some(paths) => std::env::split_paths(&paths).collect(),
        None => Vec::new(),
    }
}

/// Pure resolution engine for locating the QEMU binary across prioritized sources.
pub(crate) fn find_executable_in<F>(
    explicit_path: Option<&Path>,
    env_lookup: F,
    system_paths: &[PathBuf],
    path_dirs: &[PathBuf],
) -> Result<PathBuf, QemuError>
where
    F: Fn(&str) -> Option<String>,
{
    // 1. Explicit path parameter
    if let Some(explicit) = explicit_path {
        if is_executable(explicit) {
            return Ok(explicit.to_path_buf());
        }
        return Err(QemuError::BinaryNotFound(explicit.to_path_buf()));
    }

    // 2. Environment variable override
    if let Some(val) = env_lookup("TERMINEST_QEMU_PATH") {
        let trimmed = val.trim();
        if !trimmed.is_empty() {
            let env_path = PathBuf::from(trimmed);
            if is_executable(&env_path) {
                return Ok(env_path);
            }
            return Err(QemuError::BinaryNotFound(env_path));
        }
    }

    // 3. Platform well-known paths
    for candidate in system_paths {
        if is_executable(candidate) {
            return Ok(candidate.clone());
        }
    }

    // 4. System PATH resolution
    let binary_name = default_binary_name();
    for dir in path_dirs {
        let candidate = dir.join(binary_name);
        if is_executable(&candidate) {
            return Ok(candidate);
        }
    }

    Err(QemuError::BinaryNotFound(PathBuf::from(binary_name)))
}

/// Internal capability probing using an abstract command runner.
pub(crate) fn probe_executable_with_runner<R: CommandRunner>(
    path: &Path,
    runner: &R,
    timeout: Duration,
    max_bytes: usize,
) -> Result<QemuCapabilities, QemuError> {
    let version_raw = runner.run_bounded(path, &["--version"], timeout, max_bytes)?;
    let version = parse_version(&version_raw)?;

    let accel_raw = runner.run_bounded(path, &["-accel", "help"], timeout, max_bytes)?;
    let accelerators = parse_accelerators(&accel_raw)?;

    Ok(QemuCapabilities::new(version, accelerators))
}

/// Internal discovery and validation sequence using an abstract command runner.
pub(crate) fn discover_with_runner<R: CommandRunner>(
    explicit_path: Option<&Path>,
    policy: Option<&QemuVersionPolicy>,
    runner: &R,
    timeout: Duration,
    max_bytes: usize,
) -> Result<(PathBuf, QemuCapabilities), QemuError> {
    let path = QemuDiscovery::find_executable(explicit_path)?;
    let caps = probe_executable_with_runner(&path, runner, timeout, max_bytes)?;

    if let Some(p) = policy {
        p.validate(&caps.version)?;
    } else {
        QemuVersionPolicy::default().validate(&caps.version)?;
    }

    caps.validate_platform_support()?;

    Ok((path, caps))
}
